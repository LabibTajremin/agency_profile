# Support policy

## What is covered

- Installing, activating and configuring the product
- Bugs in the plugin, the theme or the demos
- Questions the documentation does not answer — and if you hit one, that is a documentation bug
  and gets fixed too
- Compatibility with WordPress core and with major SEO, caching and multilingual plugins

## What is not

- Custom development, custom design work, or writing your child theme for you
- Third-party plugins and their conflicts, beyond confirming which side the problem is on
- Server administration, hosting, DNS and email deliverability
- Sites where the plugin or theme files have been edited directly. Use a child theme; that is
  what it is for.

## Response

One business day, Sunday to Thursday. Complex issues get an acknowledgement in that time and a
substantive answer as we have one — an instant reply that says nothing is not faster.

## Eligibility

Support requires an active licence. An expired licence stops support and updates; **the product
keeps working**, and a lapsed licence never disables a site.

## What to send

Paste the **Edulume → System** panel. It has the versions, active plugins, PHP extensions and
file permissions that are the first four questions otherwise.

Then: what you did, what you expected, what happened. A screenshot of the wrong result beats a
description of it.

For a bug, say whether it survives with all other plugins deactivated and a default theme —
that single check resolves most reports faster than anything else you can do.

## Security

Report suspected vulnerabilities privately to the address in the plugin readme, not in a public
forum. We acknowledge within one business day and will tell you the fix timeline honestly,
including when it is going to be longer than you would like.
