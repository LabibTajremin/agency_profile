# Credits

Every bundled asset — font, icon set, image, pattern, or third-party library shipped inside
the release ZIP — is recorded here in the same commit that introduces it, with its source,
licence and licence URL. An asset without an entry is a failing pull request.

Development-only dependencies (PHPUnit, PHPStan, PHPCS, Vite, ESLint, Prettier, Vitest,
Playwright) are not bundled in the release and are therefore not listed here.
